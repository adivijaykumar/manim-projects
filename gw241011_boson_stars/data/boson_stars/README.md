# Spin-induced-quadrupole-moments-of-boson-stars
A data repository accompanying **arXiv:2511.17341**. The files contain numerically computed families of rotating boson star solutions (with $m=1$). The naming conventions are as follows:

- potential name: solitonic, repulsive or axionic
- coupling: sigma, lambda or f
- coupling strength given as a numerical value

  E.g. ```solitonic_sigma_0.05.txt``` corresponds to data for a solitonic potential with $\sigma = 0.05$.

The columns (as also annotated in the file headers) correspond to the following physical quantities:

boson star frequency $\omega$ | mass | angular momentum $J$ | $r_{99}$, the areal radius at which 99% of the mass is contained | areal radius at which 95% of the mass is contained | compactness based on $r_{99}$ | reduced SIQM (aka $\kappa$)
